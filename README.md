## 🌟 Fonctionnalités

- 📦 **Catalogue Produits Dynamique :** Affichage en grille responsive avec filtrage par catégorie, recherche instantanée et pagination.
- 🛒 **Gestion du Panier (Cart Management) :** Ajout/suppression d'articles en direct, ajustement dynamique des quantités et calcul automatique des totaux.
- 🔍 **Fiche Produit Détaillée :** Galerie d'images, description, prix, disponibilité en stock et avis clients.
- ⚡ **Performance Ultra-Rapide :** Bundler Vite dernière génération pour un Hot Module Replacement (HMR) instantané.
- 🎨 **Interface Moderne & Épurée :** Iconographie avec `lucide-react`, animations douces et design 100% responsive (Mobile, Tablette, Desktop).


## 🚀 Installation & Démarrage

### Prérequis
- [Node.js](https://nodejs.org/) (version 18 ou supérieure)
- npm ou yarn

### Étapes d'installation

1. **Cloner le dépôt :**
   ```bash
   git clone https://github.com/yassir-el-manssouri/projet-ecommerce-app.git
   cd projet-ecommerce-app
   ```

2. **Installer les dépendances :**
   ```bash
   npm install
   ```

3. **Lancer le serveur de développement :**
   ```bash
   npm run dev
   ```
   L'application sera accessible sur `http://localhost:5173`.

4. **Compiler pour la production :**
   ```bash
   npm run build
   ```
